# 🌟 Project Overview

The **School Management System** is a **Django Full Stack Web Application** developed to simplify academic management for students. The project provides a clean and responsive dashboard where students can access important academic information in one place.

The application demonstrates full-stack web development using Django by integrating backend logic, database management, authentication, and responsive frontend design.

This project was created as a learning project to gain hands-on experience with Django, CRUD operations, authentication, database integration, and dashboard development.

# 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/SchoolManagementSystem.git
```

### Navigate to Project

```bash
cd SchoolManagementSystem
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Environment

Windows

```bash
venv\Scripts\activate
```

Linux / Mac

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Apply Migrations

```bash
python manage.py migrate
```

### Run Server

```bash
python manage.py runserver
```

Visit

```
http://127.0.0.1:8000/
```
